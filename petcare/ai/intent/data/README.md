# Қазақша сұрақтар жиынтығы

`train.csv` моделін үйретуге арналған. Бір отбасына мағыналас екі тұжырым біріктірілген. Қалған CSV файлдарында сұрақтың күтілетін санаты мен мәтіні сақталады. Бағалау жиынтықтары қалыпты қазақша сөйлемдерді, қысқа ауызекі сұрақтарды және нақтылауды қажет ететін өтініштерді қамтиды. Деректер осы оқу жобасы үшін жасалған.

Нақты бөліну тәртібі, метрикалар және қате жіктелген мысалдар [модель картасында](../model_card.md) және [бағалау нәтижелерінде](../evaluation.json) берілген.
