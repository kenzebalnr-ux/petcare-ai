# PetCare AI экрандары

Суреттер Windows-тағы жұмыс істеп тұрған PySide6 қолданбасынан 1280 × 820 өлшемінде алынды.

| Экран | Көрсетілетін әрекет |
|---|---|
| [Негізгі бет](home.png) | Күндік тапсырмаларды, күйін және жоспарланған күтімді қарау |
| [Жануарларым](registry.png) | Жануарды іздеу, сүзу және таңдау |
| [Жануар қосу](add.png) | Жаңа жануар туралы дерек енгізу |
| [Жануарды өңдеу](edit.png) | Тіркелген жануардың карточкасын өзгерту |
| [Ақылды көмекші](adviser.png) | Қазақша сұрақтың санатын және журналға сүйенген жауапты көру |

Figma-дағы бағандар, Inter қарпі, қара табан логотипі және түстер сақталған. Кестеде нақты сүзгілер мен өңдеу батырмалары, формаларда күн мен санды енгізуге арналған Qt өрістері бар. Чат үлгі мәтіннің орнына екі модельдің нақты нәтижесін көрсетеді.
